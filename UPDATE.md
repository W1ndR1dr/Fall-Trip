# Update routine: refresh before the trip

Run this **Wednesday, Oct 7** (after the Mono County report posts, usually by 6 pm) and, if you like, again **Friday morning** before leaving. It takes about 10 minutes.

## The easy way: ask Claude

Open this repo in Claude Code and paste:

> Run the Fall Trip update routine in UPDATE.md: refresh conditions, update the color report from this week's Mono County and CaliforniaFallColor reports, recheck any closures or hours flagged in research-notes.md, run the offline test, and push to the deploy branch.

## By hand

1. **Pull live conditions** (NWS forecasts for Mammoth, June Lake, Lee Vining, Tioga Pass, and Bishop, plus Tioga status from NPS and Caltrans text for 120, 395, and 108):

   ```sh
   npm run update        # = node scripts/update-conditions.mjs && node scripts/build.mjs
   ```

   By Oct 7 the NWS 7-day forecast reaches Oct 9–11, and the Plan screen starts showing it automatically.

2. **Refresh the color report.** Edit `colorReport` in `src/js/content/trip.js`:
   - Read the latest:
     - Mono County (Wednesdays): https://www.monocounty.org/things-to-do/fall-colors
     - CaliforniaFallColor (Fridays): https://californiafallcolor.com/
     - Visit Mammoth: https://www.visitmammoth.com/blogs/find-fall-colors/
   - For each spot, update `now`, `proj`, and `level` (1 = Just Starting … 4 = Peak … 5 = Past Peak), plus `rank` and `warn`.
   - Update `asOf`, `summary`, and `RETRIEVED` at the top of the file.
   - If the color shifted, adjust the Saturday plan in `days` (for example, swap Lundy for Convict or McGee).

3. **Recheck the shaky items** listed under "Could not verify" in `research-notes.md`:
   - Whoa Nellie Deli's season: call 760-647-1088.
   - Silver Lake Café: call 760-648-7525.
   - Inyo Craters closure.
   - Leaves in the Loop schedule (junelakeloop.org).

4. **Test offline:**

   ```sh
   npx serve dist -l 5173 &   # or: cd dist && python3 -m http.server 5173
   npm run test:offline
   ```

5. **Deploy:** commit and push to the deploy branch. The GitHub Actions workflow (`.github/workflows/pages.yml`) builds and publishes to GitHub Pages in about a minute.

6. **Update the phones.** Open Fall Trip on each device **while online**. A "fresh version is ready" message appears; tap it. Then do a quick airplane-mode check.

## Files

| File | What it holds |
|---|---|
| `src/js/content/trip.js` | Itinerary, activity menu, color report, links, recipes |
| `src/js/content/conditions.js` | Generated by the update script (don't edit) |
| `src/js/content/devotions.js`, `scripture.js` | Devotions and the verified ESV/NIV text |
| `src/js/content/kids.js`, `packing.js` | Kid content and the packing list |
| `scripts/build.mjs` | Copies `src/` → `dist/` and stamps the service worker precache and version |
| `scripts/test-offline.mjs` | Cuts the network and checks every screen |
